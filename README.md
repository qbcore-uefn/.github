# QBCore UEFN community standards

This repository contains the organization-wide community health files used by
the repositories in the `qbcore-uefn` organization.

GitHub applies these defaults when an individual repository does not provide a
local override.

## Included standards

- Structured forms for bug reports, feature requests, and documentation issues
- Issue routing for documentation and community support
- A standard pull request description and review checklist
- Organization-wide contribution and support guidance
- A community Code of Conduct with private reporting through Discord staff
- A coordinated security disclosure policy using GitHub private reporting
- Governance roles, delegated responsibilities, and final decision authority

Repository-specific build, testing, ownership, and release configuration stays
in the repository that it governs.
