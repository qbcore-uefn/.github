# QBCore UEFN support

GitHub issues are for reproducible defects, feature proposals, and documentation
problems in official QBCore UEFN projects. They are not a general installation
or project-configuration help desk.

## Before asking for help

1. Read the [official QBCore UEFN projects](https://github.com/qbcore-uefn).
2. Search the affected repository's open and closed issues.
3. Test with current official projects and compatible dependencies.
4. Reduce the problem to the smallest reproducible example.

For installation, configuration, migration, and usage questions, use the
[official QBCore Discord](https://discord.gg/qbcore).

When requesting help, include the affected project or module, exact versions or
commits, UEFN and Fortnite ecosystem versions, test environment, reproduction
steps, and a short redacted log excerpt. Explain any modifications to official
projects.

Do not publish passwords, tokens, webhook URLs, license keys, database
credentials, player identifiers, private project or island data, or security vulnerability
details. Follow the [security policy](SECURITY.md) and report vulnerabilities
privately through the affected repository's **Security** tab.
